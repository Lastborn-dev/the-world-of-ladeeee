# The World of Ladeeee

A private, mobile-first birthday keepsake built with Next.js and a warm vintage scrapbook aesthetic.

## Local development
Run npm install, then npm run dev.

## Required Vercel environment variables
- SITE_PASSWORD: the shared private entrance password.
- SESSION_SECRET: a random secret of at least 32 characters.

Use .env.example for placeholders. Never commit real secrets.

## Current foundation
- Server-side password validation.
- HTTP-only session cookie, secure in production.
- Protected /home route.
- Responsive vintage paper visual foundation.
- Placeholder for the selected framed portrait.

Gallery, letters, games, scrapbook, soundtrack, birthday film and Chapter 20 celebration are planned for later stages.
